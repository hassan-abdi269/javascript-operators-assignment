# JavaScript Operators Assignment

## Beginner JavaScript Practice

Welcome to the JavaScript Operators Assignment!

1. Arithmetic Operators
2. Assignment Operators

## Part 1: Arithmetic Operators

Arithmetic operators perform mathematical calculations.

| Operator | Name | Example |
|---|---|---|
| + | Addition | 10 + 5 |
| - | Subtraction | 10 - 5 |
| * | Multiplication | 10 * 5 |
| / | Division | 10 / 5 |
| % | Modulus | 10 % 3 |
| ** | Exponentiation | 2 ** 3 |
| ++ | Increment | number++ |
| -- | Decrement | number-- |

## Part 2: Assignment Operators

Assignment operators assign values to variables or update their existing values.

| Operator | Example | Equivalent |
|---|---|---|
| = | x = 10 | Assign 10 to x |
| += | x += 5 | x = x + 5 |
| -= | x -= 5 | x = x - 5 |
| *= | x *= 5 | x = x * 5 |
| /= | x /= 5 | x = x / 5 |
| %= | x %= 5 | x = x % 5 |
| **= | x **= 2 | x = x ** 2 |

### Questions

Declare and work with these variables in assignment.js:

1. Declare score and assign it 50.
2. Declare additionScore with 20. Use += to increase it by 10.
3. Declare subtractionScore with 50. Use -= to decrease it by 15.
4. Declare multiplicationScore with 5. Use *= to multiply it by 4.
5. Declare divisionScore with 100. Use /= to divide it by 5.
6. Declare modulusScore with 17. Use %= to find the remainder after division by 5.
7. Declare exponentiationScore with 3. Use **= to raise it to the power of 2.
